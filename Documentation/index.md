# Blueprint

A production-grade iOS architecture reference built with modern SwiftUI.

The example app is **Discover** — it shows Points of Interest (POIs) using the Geoapify API. Every technical decision exists to teach.

## What you'll find here

- Step-by-step chapters covering architecture decisions
- Real Swift code from the Discover app
- Patterns you can copy into your own projects

Browse the [chapters](/chapters/) to get started.
